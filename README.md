# TapeTape

TapeTape 是一个以隐匿、安全为第一原则的加密聊天 App，消息经由 **TapeRelay 中继网关**传递，内置链上钱包和 DeWEB 广场浏览器。支持 iOS 和安卓。

## 能做什么

- **端到端加密聊天**：单聊、群聊（最多 500 人）、图片、视频、文件、语音、回复、转发、反应、已读回执、消息定时销毁。消息在发出前就在手机上加密，通信节点只负责传递，看不到内容。
- **不需要手机号和邮箱**：用 12 个助记词生成身份，地址就是你的身份，换手机时用助记词或备份恢复。
- **大附件**：超过约 170 KB 的图片、视频、文件加密分块存到 TapeRelay 的通信节点上，至少两台存好才算发出；接收方逐块核对 SHA-256 哈希后再解密（端侧验证）。单个文件最大 100 MB。
- **钱包**：X Layer 和 BNB Chain，支持收款、转账、聊天里发红包和转账（链上合约，未领取 7 天后可退回）、链上小店。
- **广场**：内置 Tapekit 内核的 DeWEB 浏览器，输入 `1.2.0` 这样的链上名字即可打开存在链上的网站，内容读链后逐个核对哈希再显示；内置网页钱包，连接、签名、交易都要在 App 自己的确认框里逐笔同意。

## 消息怎么传递

- 每个用户的消息身份形如 `key:0x地址@通信节点主机:4246`，加密密钥由钱包私钥派生。
- 消息发给 TapeRelay 中继网关里的**通信节点**，通信节点之间转交给收件人所在的通信节点，收件人取走后即删除。发消息不需要 gas，也不上链。
- 可用的通信节点不经过任何中心目录：App 注册时直接读 X Layer 上的**链上网关注册表**和质押合约，挑出状态正常的运营方，再逐台核对通信节点自报的运营方编号与链上一致。
- 陌生人第一次只能发一条消息，双方加好友后才互相放行，防止骚扰。

## 目录

| 目录 | 内容 |
|---|---|
| `core/` | Rust 内核 `tapetape-core`（账号、消息、群、钱包、红包、小店、备份、代理、网页钱包），通过 UniFFI 给两端调用；`crates/taperelay/` 是 TapeRelay 协议库 |
| `android/` | 安卓 App（Jetpack Compose，minSdk 26） |
| `ios/` | iOS App（SwiftUI，iOS 16+），含分享扩展 |
| `browser/` | 广场浏览器的内置脚本（Tapekit 内核宿主、网页钱包注入脚本） |
| `contracts/` | 红包 / 转账合约（Foundry） |
| `files-backend/` | 大附件签名与 RPC 中转后台（部署在 tapetape.org） |
| `spec/` | 规格：架构、消息协议、内核接口 |
