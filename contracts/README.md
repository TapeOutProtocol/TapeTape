# TapeTape 红包合约（TapeTapeRedPacket）

替换旧的 `MailChatRedPacket`（BSC `0xa71f…A7F3`、X Layer `0xde07…1D84`）。旧合约的领取签名不绑定领取人，第一个人领取后签名公开在链上，任何人都能换地址把剩下的份额领走。

## 执行思路

| 项目 | 旧合约 | 新合约 |
|---|---|---|
| 领取凭证 | 发送者对红包 ID 的签名，谁拿到谁能领 | 每个红包随机生成一把一次性「领取密钥」，创建时把它的地址存进合约；私钥放在端到端加密的红包消息里 |
| 领取签名 | 只签红包 ID | 领取密钥签 `keccak256(abi.encode(CLAIM_TAG, chainId, 合约地址, 创建者, keccak256(红包ID), 领取人))`（加 EIP-191 前缀），合约用 `msg.sender` 当领取人校验，签名挪给别人用无效 |
| 红包 ID | 全局一张表，别人可以抢先占用你的 ID | 按创建者隔开：存储键 = `keccak256(abi.encode(创建者, ID))`，ID 永不复用（退款后也不行）；只允许 `[0-9A-Za-z-]`，1–64 字节 |
| 1:1 转账 | 发送者也有签名，可以在对方领取前自己领回 | 创建时填 `recipient`（只能配 1 份），只有这个地址能领，不需要领取签名（收款人丢了聊天记录，也能在区块浏览器上直接调用 `claimRedPacket` 领取，客户端里没有卡片就没有入口）；发送者 7 天内撤不回 |
| 退款 | 只能退回创建者自己 | 仍只有创建者能发起，但可以指定收款地址（创建者被代币拉黑时也能取回） |
| 可升级 | UUPS 代理，主人可以换代码、取走全部托管资金 | **不可升级**，部署后代码固定，主人碰不到托管资金 |
| 手续费 | 主人随时可改到 10%，发红包的人不知情 | 上限 5%；发红包时带 `maxFeeRate`，链上费率比它高就拒绝。客户端在 `chain.rs` 里按链写死可接受的费率（等于部署时的费率），主人事后调高，旧版客户端会停发并提示更新，不会悄悄多扣 |
| 最小金额 | 所有代币共用一个数（BEM 门槛 10 万个） | 每个代币单独设 `minAmount[token]`，默认 0 |
| 份额下限 | 扣费后可能不够每份 1 个最小单位 | 扣费后的净额必须 ≥ 份数，每份至少 1 |
| 特殊代币 | 不检查 | 拒绝转账时扣费的代币（实际到账必须等于金额）；事后才变余额的代币拦不住，见已知局限 |
| 份数 | 不限 | 1–1000 |

保持不变：每个地址只能领一次；随机金额算法（最多平均数的两倍）；7 天后创建者可退回剩余，退回后不能再领；没退回之前仍可领取。

## 主人能做什么

只有这三件事，都不能动用户托管的钱（`renounceOwnership` 已禁用，防止手续费永久锁死）：

- `setFeeRate(费率)`：千分比，0–50。
- `setMinAmount(代币, 最小金额)`：代币填 `0x0000000000000000000000000000000000000000` 表示原生币。
- `withdrawFees(代币, 收款地址)`：提走这个代币累计的手续费。

主人转移是两步的（`transferOwnership` 之后要新主人 `acceptOwnership`），防止填错地址。

## 已知局限（设计上接受）

- **任何一个群成员都可以抢光整个红包**：领取密钥群里人人都有，签名只绑定领取地址。一个成员可以离线给很多个自己的地址签好名，用一个合约在一笔交易里逐个领完（审计实测 200 份一笔交易领光），或者用脚本开很多钱包分别领。`tx.origin` 限制只能挡住一笔交易的做法，挡不住多钱包。根治要发送方给每个成员单独签名，和「群里先到先得」的玩法冲突，不做。所以红包只适合发给信得过的群。
- **随机金额可预测、可重试**：金额由区块时间、`prevrandao`、领取人地址等决定，交易前就能精确算出；用合约领取还能不满意就回滚、下个区块再试，稳定拿到接近平均数两倍。总额不变，局外人拿不到钱，只影响群成员之间怎么分。
- **被移出群的人**：他手里还有之前红包的领取密钥，在份额领完前还能领。
- **事后才变余额的代币**：创建时只核对一次到账。代币如果之后对合约扣税、冻结、负向调整余额，同一种代币的红包会资不抵债，后领的人领不到。只影响那一种代币，其他代币的记账是分开的。客户端只接受配置表里的代币（BNB、OKB、USDT、USDC、USD1、BEM）。
- **误转进来的钱取不回**：直接 `transfer` 给合约的代币没有找回功能（加找回会给主人多一条碰钱的路，不做）。合约不接收直接转入的原生币。
- **手续费不退**：手续费在创建时一次收走，没人领、全额退回时手续费也不退。
- **红包 ID 区分大小写**：`ABC` 和 `abc` 是两个红包。
- **领取要自付燃料费**：领取人钱包里要有一点原生币（BNB / OKB）付交易费，余额为零的新用户领不了。
- **7 天后仍可领取**：合约在退款之前一直允许领取；客户端过期后不再显示「领取」按钮，这是客户端的选择。

## 构建与测试

```sh
cd tapetape-v2/contracts
forge install --no-git OpenZeppelin/openzeppelin-contracts@v5.1.0 foundry-rs/forge-std   # 第一次
forge test
```

编译设置：solc 0.8.28，evmVersion paris（X Layer 兼容），优化 200 次。
部署页面见 `deploy/`。
